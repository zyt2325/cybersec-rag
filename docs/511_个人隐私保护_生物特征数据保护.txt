生物特征数据保护

一、基本概念  
1. 生物特征数据指个体固有的生理或行为特征经数字化采集形成的唯一性标识，如指纹模板、虹膜图像哈希值、声纹频谱特征向量。  
2. 与传统口令不同，生物特征具有不可撤销性：一旦泄露，用户无法通过“重置”恢复原始生物特征。  
3. 法律定义上，《个人信息保护法》第28条将人脸、指纹、声纹等明确列为敏感个人信息，处理需单独同意及事前影响评估。  
4. 生物特征数据不等于原始生物信号：系统实际存储和比对的是经特征提取、降维、加密处理后的模板，而非高清图像或原始波形。  

二、原理与关键机制  
1. 模板保护技术是核心：采用可撤销模板（Cancelable Biometrics）或模糊提取器（Fuzzy Extractor），确保同一生物源在不同系统生成不可关联的模板。  
2. 活体检测（Liveness Detection）通过多光谱成像、微表情分析或时序纹理变化识别照片、面具、3D打印模型等伪造攻击。  
3. 匹配过程通常在可信执行环境（TEE）中完成，如ARM TrustZone或Intel SGX，防止模板在内存中被恶意进程读取。  
4. 零知识证明可用于验证身份而不暴露模板：用户证明自己拥有匹配模板的私钥，验证方仅获“通过/拒绝”结果。  

三、典型类型与常见问题  
1. 人脸数据易受对抗样本攻击：微小扰动可导致深度学习模型误判，且原始图像常被无加密上传至云端服务器。  
2. 指纹传感器存在残留信息风险：电容式传感器表面可能残留静电指纹印痕，被高精度光学设备复原。  
3. 声纹系统在信道噪声下鲁棒性差，常被迫降低阈值，导致冒认率（FAR）上升，且语音样本易从通话录音中截获。  
4. 多模态融合若设计不当，反而扩大攻击面：例如人脸+声纹联合认证中任一模态泄露，可能辅助破解另一模态。  

四、防御措施与实践建议  
1. 禁止明文存储生物特征：必须使用加盐哈希、同态加密或基于硬件的安全模块（HSM）保护模板，密钥不得与模板共存于同一设备。  
2. 实施最小化采集原则：仅提取必要特征维度（如指纹的12个 minutiae 点而非全图），并立即丢弃原始采集数据。  
3. 强制部署活体检测与反欺骗测试：每季度用ISO/IEC 30107-3标准中的打印攻击、视频回放、3D面具样本进行渗透验证。  
4. 建立模板生命周期管理：设定模板自动过期策略（如90天），支持用户主动注销并触发后端模板不可逆擦除。  
5. 对第三方SDK实施严格审计：要求提供FIDO2认证、源码级安全审查报告，并禁止其将生物数据同步至境外服务器。
