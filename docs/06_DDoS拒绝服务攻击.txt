DDoS分布式拒绝服务攻击与防御

DDoS（Distributed Denial of Service，分布式拒绝服务攻击）是指攻击者控制大量肉鸡，同时向目标服务器发送海量请求，耗尽其带宽或计算资源，导致正常用户无法访问。

一、攻击原理
1. 攻击者先入侵大量计算机，组成僵尸网络（Botnet）
2. 同时向目标发送海量请求
3. 目标服务器带宽占满、CPU/内存耗尽
4. 正常用户无法访问服务

二、常见攻击类型
1. 流量型攻击：UDP Flood、ICMP Flood、DNS Query Flood，占满带宽
2. 连接型攻击：SYN Flood，耗尽服务器连接表
3. 应用层攻击：HTTP Flood，模拟正常请求耗尽服务器资源
4. 反射放大攻击：DNS/NTP反射，利用第三方服务器放大攻击流量

三、与DoS的区别
- DoS是单台机器发起攻击
- DDoS是成百上千台机器同时攻击，流量更大更难防御

四、防御方法
1. 流量清洗：接入高防IP，异常流量在边缘被过滤
2. CDN加速：将静态内容分发到边缘节点，隐藏源站
3. 带宽扩容：预留足够带宽应对突发流量
4. 防火墙规则：限制单IP连接数，丢弃异常报文
5. Anycast网络：多节点分散流量
6. 应用层限流：Nginx限流、WAF拦截恶意请求

五、常见攻击端口
- 80/443（Web服务）
- 53（DNS）
- 123（NTP）
- 1900（SSDP）
