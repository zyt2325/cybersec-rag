对抗样本攻击

一、基本概念  
1. 对抗样本是经过精心设计的输入数据，对人类不可察觉，却可导致机器学习模型输出错误结果。  
2. 该攻击针对深度神经网络等判别式模型，尤其在图像、语音、文本等感知任务中高发。  
3. 对抗性并非源于数据噪声或自然扰动，而是通过优化算法引入的微小、定向扰动。  
4. 攻击者无需访问模型内部结构，仅凭黑盒查询即可构造有效对抗样本。  
5. 典型场景包括自动驾驶误识停车标志、人脸识别系统被欺骗绕过身份验证。

二、原理与关键机制  
1. 模型决策边界在高维空间中存在局部线性特性，微小扰动可跨过边界引发误分类。  
2. 梯度信息是核心线索：白盒攻击利用损失函数对输入的梯度方向生成扰动。  
3. 扰动幅度受限于Lp范数（如L∞≤8/255），确保人眼难以分辨原始与对抗图像。  
4. 迁移性使对抗样本可在不同模型间生效，源于不同网络学习到相似的特征表示偏差。  
5. 非凸优化过程使对抗样本构造具有确定性，但最优扰动求解为NP难问题。

三、典型类型与常见问题  
1. 白盒攻击依赖完整模型知识（参数、结构、梯度），如FGSM、PGD、C&W攻击。  
2. 黑盒攻击通过API查询或替代模型训练实现迁移攻击，成功率受模型架构相似性影响。  
3. 物理世界攻击需考虑光照、角度、打印失真等现实约束，鲁棒性显著低于数字域。  
4. 目标攻击强制模型输出指定错误类别，非目标攻击仅要求输出任意错误类别。  
5. 对抗样本泛化能力差：单一样本通常无法稳定欺骗同一模型的不同输入批次。

四、防御措施与实践建议  
1. 对抗训练是最有效方法之一，将对抗样本加入训练集并联合优化模型鲁棒性。  
2. 输入预处理可缓解部分攻击，如JPEG压缩、随机裁剪、总变差最小化滤波。  
3. 检测机制包括检测输入梯度异常、预测置信度分布偏移或使用辅助鉴别器。  
4. 鲁棒特征学习通过正则化（如IBP、CROWN）约束中间层激活响应范围。  
5. 实际部署应避免单一模型决策，结合多模型集成、输出一致性校验与人工复核流程。  
6. 安全评估须覆盖多种攻击算法与扰动强度，在数字域和可控物理场景下分别测试。
