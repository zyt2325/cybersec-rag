椭圆曲线密码ECC

一、基本概念  
1. ECC是基于椭圆曲线离散对数问题（ECDLP）的公钥密码体制，用更短密钥实现与RSA相当的安全强度。  
2. 椭圆曲线定义在有限域上，常见域为素域F_p（p为大素数）或二元域F_{2^m}，密码学应用以F_p为主。  
3. 曲线方程标准形式为y² ≡ x³ + ax + b (mod p)，需满足判别式4a³ + 27b² ≠ 0 (mod p)以保证光滑性。  
4. 椭圆曲线上点构成阿贝尔群，加法运算通过弦切线法则定义，含无穷远点O作为加法单位元。  

二、原理与关键机制  
1. 私钥为随机选取的整数d（1 < d < n），n为基点G的阶（即nG = O），公钥为Q = dG，属标量乘法运算。  
2. ECDLP难题指：已知G和Q = dG，求d在计算上不可行，当前最优算法复杂度为O(√n)，远高于RSA分解难度。  
3. 密钥协商（ECDH）双方各自生成私钥d₁、d₂，交换公钥Q₁、Q₂后计算共享密钥d₁Q₂ = d₂Q₁ = d₁d₂G。  
4. 数字签名（ECDSA）利用私钥对消息哈希值签名，验证时依赖椭圆曲线群运算与模逆运算的正确性校验。  

三、典型类型与常见问题  
1. NIST推荐曲线P-256、P-384、P-521采用素域F_p，而Curve25519（由Bernstein设计）使用蒙哥马利形式y² = x³ + 486662x² + x，抗侧信道攻击能力强。  
2. 若随机数k在ECDSA签名中重复使用，攻击者可直接推导私钥d，故k必须每次签名唯一且强随机。  
3. 无效曲线攻击利用协议未验证输入点是否在合法曲线上，诱导计算至弱阶子群，泄露私钥部分信息。  
4. 小子群攻击针对基点G阶n含小素因子的情形，若签名或密钥交换中未验证点阶，可能被降维破解。  

四、防御措施与实践建议  
1. 优先选用经广泛审计的曲线，如Curve25519（密钥交换）、Ed25519（签名），避免自定义或NIST未验证曲线。  
2. 实现中必须对所有输入点执行有效性验证：检查坐标是否在域内、是否满足曲线方程、是否为无穷远点、阶是否整除n。  
3. 签名过程强制使用确定性RFC 6979标准生成k，消除随机源缺陷导致的密钥泄露风险。  
4. 密钥派生与协商需结合密钥确认机制（如ECDH with Key Confirmation），防止中间人篡改公钥参数。  
5. 硬件实现应启用恒定时间标量乘法（如固定窗口法或Montgomery ladder），阻断时序与功耗侧信道分析。
