RSA算法原理  
一、基本概念  
1. RSA是一种非对称加密算法，由Rivest、Shamir和Adleman于1977年提出，基于大整数质因数分解的数学难题。  
2. 密钥对包含公钥（n, e）和私钥（n, d），其中n为两个大素数p与q的乘积，e与φ(n)=(p−1)(q−1)互质。  
3. 加密过程为c ≡ m^e mod n，解密为m ≡ c^d mod n，满足ed ≡ 1 mod φ(n)，确保可逆性。  
4. RSA同时支持加密与数字签名：签名用私钥运算，验证用公钥运算，依赖同一数学结构。  

二、原理与关键机制  
1. 安全性根植于大整数分解困难性：已知n，若无法高效分解出p、q，则无法计算φ(n)，进而无法推导d。  
2. 欧拉定理是解密正确性的核心：当gcd(m,n)=1时，m^φ(n) ≡ 1 mod n，由此导出m^(ed) ≡ m mod n。  
3. 密钥生成中，p与q需为强素数且长度相近（如各1024位），避免Pollard-p−1等特殊分解攻击。  
4. 指数e常取65537（2^16+1），兼顾安全性与运算效率；d必须严格保密，且长度应接近n的比特长度。  

三、典型类型与常见问题  
1. 低指数攻击：当e=3且明文m较小（m^3 < n）时，密文c开三次方即可直接恢复m，无需私钥。  
2. 共模攻击：多个用户共用相同n但不同e、d时，若同一消息用不同公钥加密，可能通过中国剩余定理恢复明文。  
3. 定时攻击与功耗分析属于侧信道攻击，利用解密运算时间或硬件功耗差异推测私钥比特位。  
4. 随机数生成缺陷导致p、q重复或过于接近，使n易被Fermat分解法攻破，常见于嵌入式设备密钥生成环节。  

四、防御措施与实践建议  
1. 使用至少2048位模长n，推荐3072位或以上；禁用1024位及以下密钥，因其已被实际分解验证不安全。  
2. 密钥生成必须采用密码学安全伪随机数生成器（CSPRNG），确保p、q独立、均匀、不可预测。  
3. 实际应用中须结合OAEP填充方案（而非PKCS#1 v1.5），防止选择密文攻击与明文结构泄露。  
4. 签名操作前应对消息哈希后加盐并使用PSS填充，避免RSA裸签名导致的伪造与长度扩展风险。  
5. 服务端实现应启用恒定时间模幂运算，屏蔽分支与内存访问时序差异，抵御定时侧信道攻击。  
6. 定期轮换密钥并审计密钥生命周期，私钥存储须使用HSM或可信执行环境（TEE），禁止明文落盘。
