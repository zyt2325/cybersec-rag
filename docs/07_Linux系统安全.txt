Linux系统安全基础

Linux是服务器最常用的操作系统，其安全配置直接影响系统整体安全。

一、用户与权限管理
1. root用户：超级管理员，拥有最高权限，日常操作尽量不用root
2. sudo机制：普通用户临时获得root权限，记录操作日志
3. 用户组：将用户分组，按组分配权限
4. 文件权限：r(读4) w(写2) x(执行1)，如755表示所有者读写执行，其他人读执行
5. 修改权限：chmod、chown、chgrp

二、SSH安全配置
1. 修改默认端口22为其他端口
2. 禁止root直接登录：PermitRootLogin no
3. 使用密钥登录替代密码登录
4. 限制可登录用户：AllowUsers user1 user2
5. 设置登录超时和失败次数限制

三、防火墙配置
- iptables/firewalld控制端口访问
- 只开放必要端口：80(HTTP)、443(HTTPS)、22(SSH)
- 默认拒绝所有入站，只放行白名单

四、日志审计
- /var/log/auth.log：登录日志
- /var/log/syslog：系统日志
- /var/log/nginx/：Web服务日志
- 使用last、lastb查看登录记录

五、常见安全加固
1. 及时更新系统：apt update && apt upgrade
2. 关闭不必要的服务和端口
3. 安装fail2ban自动封禁暴力破解IP
4. 设置强密码策略
5. 定期备份重要数据
6. 禁用不必要的SUID程序
