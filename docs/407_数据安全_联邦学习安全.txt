联邦学习安全

一、基本概念  
1. 联邦学习是一种分布式机器学习范式，允许多个参与方在不共享原始数据的前提下协同训练全局模型。  
2. 安全目标包括保护本地数据隐私、防止模型反演攻击、抵御恶意客户端投毒及保障聚合过程可信性。  
3. 典型架构含中心服务器（协调方）与多个客户端（数据持有方），通信内容主要为模型参数或梯度更新。  
4. 与传统集中式学习相比，其核心安全挑战源于参数上传带来的信息泄露风险及异构参与方的不可信假设。  

二、原理与关键机制  
1. 模型聚合采用加权平均（如FedAvg），权重通常与客户端本地样本量成正比，但该机制易受异常更新干扰。  
2. 差分隐私通过向梯度或参数添加可控噪声，量化约束单个样本对输出的影响，提供可证明的隐私保障。  
3. 安全多方计算（SMC）支持在加密状态下执行聚合运算，常见方案包括秘密共享与同态加密组合实现。  
4. 可验证聚合机制引入数字签名或零知识证明，使服务器能验证客户端提交更新的合法性与完整性。  

三、典型类型与常见问题  
1. 横向联邦学习中，各客户端特征空间一致但样本分布不同，面临成员推断与梯度反演等隐私泄露风险。  
2. 纵向联邦学习下，各方样本重叠但特征互补，需安全对齐ID，易受隐私集合求交（PSI）协议侧信道攻击影响。  
3. 恶意客户端可通过构造异常梯度实施模型投毒，导致全局模型在特定后门触发下产生错误预测。  
4. 中心服务器若被攻陷，可能篡改聚合逻辑或窃取中间参数，破坏系统整体信任锚点。  
5. 通信链路未加密时，参数传输易遭中间人截获，梯度可被用于重建原始输入图像或文本片段。  

四、防御措施与实践建议  
1. 在客户端本地训练阶段启用梯度裁剪与噪声注入，限制单次更新对全局模型的影响幅度。  
2. 采用鲁棒聚合算法（如Krum、Median、Bulyan），识别并过滤偏离主分布的恶意参数更新。  
3. 对服务器端实施最小权限原则，分离模型聚合、参数验证与日志审计功能，避免单点故障。  
4. 强制使用TLS 1.3及以上版本加密所有客户端-服务器通信，并校验双向证书有效性。  
5. 部署客户端准入控制机制，结合硬件可信执行环境（TEE）或远程证明验证参与方运行时完整性。  
6. 定期执行模型水印检测与后门扫描，利用影子训练与异常激活分析识别潜在投毒残留。
