数据销毁与介质处置

一、基本概念  
1. 数据销毁指通过技术手段使存储介质上的数据不可恢复，确保信息无法被重建或读取。  
2. 介质处置是数据销毁后的物理处理过程，包括回收、销毁、转售或移交等合规操作。  
3. 残余数据指擦除后仍可能通过专业设备恢复的磁性/电荷残留信息，构成主要安全风险。  
4. 数据生命周期终点管理要求在设备退役、转用或报废前完成销毁，而非仅依赖逻辑删除。  
5. 合规依据包括GB/T 25069—2022《信息安全技术 术语》及等保2.0中关于介质管理的控制项。

二、原理与关键机制  
1. 磁性介质（如HDD）依赖覆写改变磁畴方向，需多轮随机覆写破坏原始信号特征。  
2. 固态存储（SSD/NVMe）因FTL映射和磨损均衡，标准覆写无效，须启用SED硬件加密自毁或ATA SECURE ERASE指令。  
3. 物理销毁通过粉碎、熔融或消磁破坏介质物理结构，使数据层不可逆损毁。  
4. 消磁仅适用于传统磁性介质，对闪存无效；强磁场需达介质矫顽力阈值以上才有效。  
5. 验证机制必须独立于销毁工具，采用抽样取证或专用扫描仪检测残余数据模式。

三、典型类型与常见问题  
1. 覆写类工具（如DBAN）对SSD失效，且未覆盖坏道或保留区易留数据痕迹。  
2. 云环境虚拟机磁盘快照、备份副本、缓存日志常被忽略，导致“销毁”后数据仍存在于其他位置。  
3. 移动设备内置eMMC/UFS芯片存在隐藏分区，厂商预置固件区可能残留用户数据。  
4. 介质移交时未清除TPM/Secure Enclave密钥，接收方可能利用密钥链恢复加密数据。  
5. 二手硬盘转售前仅格式化，未执行符合NIST SP 800-88 Rev.1的清除流程，风险极高。

四、防御措施与实践建议  
1. 实施分级销毁策略：绝密数据强制物理粉碎，机密级启用SED自毁+验证，内部数据执行3轮覆写+校验。  
2. 建立介质台账，记录序列号、销毁方式、执行人、时间及第三方验证报告，保存期不少于5年。  
3. SSD销毁前须确认是否支持NVMe Format NVM命令或ATA SECURE ERASE，并禁用TRIM干扰验证。  
4. 对含加密芯片的物联网设备，销毁前执行密钥擦除指令（如ARM TrustZone TZC寄存器清零）。  
5. 第三方处置须签订保密协议，要求其提供ISO/IEC 27001认证及销毁视频存档，禁止分包。  
6. 定期审计介质处置日志，比对资产管理系统中的退役设备清单，确保无遗漏项。
