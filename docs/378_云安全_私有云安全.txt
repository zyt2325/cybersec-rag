私有云安全

一、基本概念  
1. 私有云是专供单一组织使用的云计算环境，可部署于本地数据中心或托管设施中，资源不与其他组织共享。  
2. 与公有云相比，私有云强调控制权、合规性与定制化，但需自行承担全部安全责任边界内的防护工作。  
3. 其安全范畴涵盖虚拟化层、宿主机、网络平面、存储系统、管理平台及租户工作负载等全栈组件。  
4. 安全目标包括保障数据机密性、完整性、可用性，防止未授权访问、横向移动与配置漂移引发的越权行为。  

二、原理与关键机制  
1. 虚拟化隔离依赖Hypervisor强制执行VM间内存、CPU和I/O资源隔离，但存在侧信道攻击与逃逸风险。  
2. 软件定义网络（SDN）通过集中控制器实现微隔离策略，支持基于标签或身份的动态流量控制。  
3. 身份与访问管理（IAM）采用RBAC+ABAC混合模型，对接企业AD/LDAP，实现细粒度API级权限控制。  
4. 加密贯穿全生命周期：传输中TLS 1.2+，静态数据使用AES-256加密，密钥由专用HSM或KMS托管。  

三、典型类型与常见问题  
1. 本地部署型私有云易因物理访问控制薄弱、运维人员权限过度导致配置泄露或后门植入。  
2. 托管型私有云面临服务提供商内部威胁、多租户共用硬件引发的残余数据残留与缓存污染风险。  
3. 混合架构中API网关配置错误、跨云身份同步延迟或证书信任链断裂，可能造成认证绕过。  
4. 自动化编排工具（如Terraform、Ansible）模板硬编码凭据、未签名镜像拉取，引入供应链污染隐患。  
5. 虚拟机快照与内存转储文件若未加密存储，可能被提权攻击者提取明文凭证与密钥。  

四、防御措施与实践建议  
1. 实施最小权限原则：Hypervisor管理接口仅限专用管理网络访问，禁用默认账户并启用MFA。  
2. 部署运行时防护：在虚拟机内嵌轻量Agent，实时检测异常进程、无文件注入与内存代码注入行为。  
3. 建立配置基线并自动化审计：使用CIS Benchmarks校验vCenter、OpenStack组件配置，每日扫描偏差。  
4. 网络分段采用三层模型：管理平面、存储平面、业务平面物理/逻辑隔离，禁止跨平面直连。  
5. 对所有容器镜像实施SBOM生成与CVE扫描，阻断含高危漏洞或未知来源的基础镜像部署。  
6. 日志统一采集至独立SIEM平台，覆盖Hypervisor日志、虚拟交换机流日志、API审计日志，保留≥180天。
