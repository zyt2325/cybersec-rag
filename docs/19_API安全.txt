API安全基础

API是现在互联网应用的核心，但也是安全重灾区。

一、为什么API不安全
1. 接口多，暴露面大
2. 传统WAF不管API逻辑漏洞
3. 开发者觉得"内网接口不用鉴权"
4. 版本迭代快，安全跟不上

二、常见API漏洞
1. 未授权访问：接口不需要登录就能调
2. 越权访问：用户A能看用户B的数据（水平越权）
3. 批量数据泄露：遍历ID把全库数据拖走
4. 注入：API参数没过滤，SQL注入
5. 限流缺失：被刷接口刷爆
6. 敏感数据泄露：返回里多了身份证、手机号

三、API安全防护
1. 认证授权：每个接口都要验证
2. 输入校验：严格校验所有参数
3. 限流：防止被刷
4. 签名：防止请求被篡改
5. 脱敏：敏感字段不返回或脱敏
6. 日志审计：记录所有API调用

四、GraphQL安全
- GraphQL可以一次查很多数据，容易被批量拖库
- 需要限制查询深度和复杂度
- 防止攻击者写超级复杂的查询打爆服务器

五、API安全测试
- 枚举所有接口
- 测试未授权访问
- 测试越权
- 测试注入
- 测试限流
