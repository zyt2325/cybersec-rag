数据出境安全评估

一、基本概念  
1. 数据出境安全评估是依据《个人信息保护法》《数据出境安全评估办法》等法规，对向境外提供重要数据或个人信息前开展的强制性合规审查。  
2. 评估对象包括关键信息基础设施运营者处理的重要数据，以及处理超过100万人个人信息的主体向境外提供数据的行为。  
3. 评估核心目标是识别数据出境可能引发的国家安全风险、公共利益损害及个人权益侵害，确保境外接收方具备同等保护能力。  
4. 评估责任主体为数据处理者，须在数据出境前通过国家网信部门指定系统提交申报材料，并承担申报真实性与完整性法律责任。  

二、原理与关键机制  
1. 风险导向原则：以数据敏感度、出境规模、接收方所在国法律环境、传输技术路径为四维风险因子构建评估模型。  
2. 境外接收方约束机制：要求签订具有法律约束力的合同，明确其数据处理目的、方式、保存期限及再转移限制条款。  
3. 安全影响分析（SIA）：需对数据类型、字段粒度、脱敏程度、加密算法强度、传输通道安全性进行逐项技术验证。  
4. 动态复评机制：通过安全评估的数据出境活动，每满2年或发生重大变更（如接收方变更、数据用途扩展）须重新申报。  

三、典型类型与常见问题  
1. 典型场景包括：跨国企业员工信息同步至境外HR系统、云服务商将境内用户日志上传至境外运维中心、医疗AI公司向境外合作方提供脱敏影像数据集。  
2. 常见问题：未识别“重要数据”目录中隐含字段（如地理坐标叠加行业属性即构成测绘类重要数据）；误判匿名化效果，导致去标识化数据仍具重识别风险。  
3. 合规盲区：将数据经第三国中转视为“非直接出境”，规避评估义务；使用境外CDN节点缓存用户行为数据未纳入申报范围。  
4. 技术误用：采用弱加密协议（如TLS 1.0）传输敏感字段；API接口未实施细粒度访问控制，导致境外调用方越权获取非授权数据。  

四、防御措施与实践建议  
1. 建立数据分类分级清单，结合《重要数据识别指南》和行业目录，对拟出境数据逐字段标注类别、级别、出境必要性说明。  
2. 实施出境前技术验证：使用国密SM4加密存储、SM2签名传输，部署DLP系统拦截未授权批量导出行为。  
3. 要求境外接收方提供GDPR/当地数据保护法规合规证明，并通过第三方审计确认其安全管理制度有效性。  
4. 在合同中嵌入强制性退出条款：当接收方所在国法律要求其提供数据且可能危及我国安全时，中方有权单方终止传输并启动数据返还程序。  
5. 对出境数据流实施全链路审计：记录传输时间、IP地址、数据哈希值、操作人员身份，日志留存不少于180日且不可篡改。
