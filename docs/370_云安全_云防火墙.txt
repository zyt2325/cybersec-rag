云防火墙

一、基本概念  
1. 云防火墙是部署在云环境中的网络层与应用层访问控制设备，专为虚拟化、多租户和弹性伸缩架构设计。  
2. 区别于传统硬件防火墙，其策略执行点可动态跟随云工作负载迁移，支持API驱动的策略下发与实时更新。  
3. 核心功能包括东西向流量微隔离、南北向入口防护、日志审计与威胁情报集成，覆盖IaaS、PaaS及SaaS边界。  
4. 通常以服务形式（FWaaS）提供，由云服务商或第三方安全厂商托管，支持按需计费与自动扩缩容。  

二、原理与关键机制  
1. 基于深度包检测（DPI）与会话状态跟踪，解析HTTP/HTTPS、DNS、TLS等协议载荷，识别恶意URL与C2通信特征。  
2. 采用策略组（Policy Group）与标签（Tag）机制实现细粒度访问控制，策略可绑定至云主机、容器、K8s命名空间等逻辑实体。  
3. 集成云平台元数据（如VPC ID、安全组ID、实例标签），自动同步资产变更，避免因配置漂移导致策略失效。  
4. 支持TLS 1.2/1.3解密与重加密（SSL/TLS Inspection），对加密流量实施内容级检测，需配合证书信任链管理。  

三、典型类型与常见问题  
1. 云原生防火墙：直接嵌入云平台控制平面（如AWS Network Firewall、Azure Firewall），与VPC路由深度集成。  
2. 第三方虚拟防火墙：以VM或容器形态部署（如Palo Alto VM-Series、Fortinet FortiGate-VM），依赖云平台路由引流。  
3. 容器防火墙：运行于Kubernetes集群内，通过CNI插件拦截Pod间流量，支持NetworkPolicy扩展与运行时行为基线建模。  
4. 常见问题包括：东西向策略覆盖盲区、TLS解密性能瓶颈、跨云策略不一致、日志格式异构导致SIEM对接困难。  

四、防御措施与实践建议  
1. 实施最小权限原则，禁止默认全通策略；东西向规则应基于业务依赖图谱生成，而非仅依赖IP段。  
2. 启用日志流式导出至专用安全存储，保留原始NetFlow/IPFIX及应用层日志至少90天，用于异常横向移动分析。  
3. 对关键API网关、数据库前端部署WAF联动策略，将SQL注入、路径遍历等应用层攻击特征同步至云防火墙阻断。  
4. 定期执行策略有效性验证：使用云平台合规检查工具扫描冗余/冲突规则，并通过模拟流量测试策略命中率。  
5. 在混合云场景中，统一纳管本地防火墙与云防火墙策略，利用SD-WAN控制器或零信任网关实现策略一致性同步。
