卫星互联网安全

一、基本概念  
1. 卫星互联网是通过地球轨道卫星（含LEO、MEO、GEO）构建的全球性无线通信网络，提供宽带接入与物联网回传服务。  
2. 其安全边界跨越地面站、星间链路、用户终端及卫星平台，形成空天地一体化多域协同防护体系。  
3. 与传统地面网络相比，其长传播时延（GEO达270ms）、高动态拓扑、有限星上计算资源构成独特安全约束。  
4. 国际电信联盟（ITU）《无线电规则》和《空间物体登记公约》构成基础法律框架，但缺乏统一强制性网络安全标准。  

二、原理与关键机制  
1. 星地链路普遍采用扩频调制（如DSSS）与前向纠错（LDPC码），提升抗干扰能力，但未内生加密。  
2. 用户认证依赖PKI体系，典型方案为地面站签发X.509证书至终端，卫星仅中继不参与密钥管理。  
3. 星间激光链路使用AES-256-GCM加密，但密钥分发依赖可信地面控制中心，存在单点信任风险。  
4. 卫星载荷固件更新通过带外信道（S波段遥测链路）推送，无完整性校验机制易遭篡改。  

三、典型类型与常见问题  
1. LEO星座（如Starlink）因轨道密集、星间切换频繁，易受定向干扰与虚假星历注入攻击。  
2. GEO卫星广播特性导致下行信号全域覆盖，未经加密的遥测信道可被被动截获并逆向解析指令格式。  
3. 地面关口站若部署于境外，可能面临本地化监管缺失导致的物理访问与侧信道泄露风险。  
4. 用户终端射频前端缺乏射频指纹防护，攻击者可通过特征识别定位高价值目标并实施精准干扰。  
5. 多租户载荷共享架构下，恶意租户可能利用FPGA配置漏洞发起跨虚拟通道DMA攻击。  

四、防御措施与实践建议  
1. 强制星地链路启用TLS 1.3或DTLS 1.2，禁用RSA密钥交换，优先采用X25519+ECDHE密钥协商。  
2. 在卫星载荷FPGA中嵌入硬件信任根（RTM），对每次固件加载执行SHA-384哈希比对与签名验证。  
3. 地面站应实施地理围栏策略，限制非授权区域IP地址访问指挥控制接口，并启用双向mTLS认证。  
4. 用户终端需支持动态频谱感知，自动规避已知干扰频段，且射频发射功率按需调节以降低信号暴露面。  
5. 建立星群级安全态势感知系统，融合星上异常遥测数据（如姿态角突变、功耗异常）与地面流量基线进行关联分析。  
6. 参与3GPP TS 23.501标准演进，推动将5G SBA架构中的网络切片安全策略扩展至卫星核心网功能模块。
