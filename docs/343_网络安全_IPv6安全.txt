IPv6安全

一、基本概念  
1. IPv6采用128位地址空间，支持无状态地址自动配置（SLAAC），默认启用邻居发现协议（NDP）替代ARP。  
2. IPv6报头结构简化，取消首部校验和，依赖上层协议或链路层保障完整性。  
3. IPv6原生支持IPsec，AH与ESP为可选扩展头，但实际部署中常被禁用或未启用。  
4. 地址隐私扩展（RFC 4941）通过生成临时随机接口标识符降低主机长期追踪风险。  
5. IPv6过渡机制（如双栈、隧道封装6to4/ISATAP/Teredo）引入额外攻击面和策略绕过可能。

二、原理与关键机制  
1. 邻居发现协议（NDP）使用ICMPv6消息实现地址解析、重复地址检测和路由器通告，无认证机制。  
2. 路由器通告（RA）消息可被恶意设备伪造，诱导主机配置错误默认网关或前缀信息。  
3. 重复地址检测（DAD）依赖NS/NA交互，攻击者可抢先响应NA包实施地址劫持。  
4. ICMPv6错误消息（如Packet Too Big、Time Exceeded）可被滥用于路径探测或反射放大攻击。  
5. IPv6扩展头（如路由头RH0、分段头）曾被用于绕过防火墙规则，RFC 5095已弃用RH0并限制扩展头处理逻辑。

三、典型类型与常见问题  
1. NDP欺骗：伪造NA消息篡改目标主机的邻居缓存，实现中间人或DoS攻击。  
2. RA洪泛攻击：持续发送伪造RA消息导致主机频繁重配置网络参数，引发连接中断。  
3. IPv6隧道滥用：利用企业边界设备对Teredo/6to4流量过滤不足，建立隐蔽C2通信通道。  
4. 地址扫描难度提升但未消除：/64子网内仍存在可预测性（如EUI-64、DHCPv6 IAID泄露）。  
5. 安全设备盲区：部分防火墙、IDS/IPS未启用IPv6深度包检测，或ACL规则未同步覆盖IPv6地址族。  
6. 双栈环境配置失配：IPv4策略严格而IPv6策略宽松，形成策略缺口供攻击者利用。

四、防御措施与实践建议  
1. 启用RA Guard（RFC 6105）在交换机端口级过滤非法RA消息，仅允许可信端口转发。  
2. 部署SEND协议（RFC 3971）结合CGA和RSA签名验证NDP消息来源，替代原始无认证NDP。  
3. 在边界设备上禁用不必要过渡机制（如Teredo、6to4），显式丢弃对应协议号（IPPROTO_IPV6）隧道包。  
4. 对IPv6地址分配实施严格策略：禁用EUI-64，强制使用RFC 7217稳定隐私地址，限制DHCPv6租期。  
5. 同步更新安全策略：确保防火墙ACL、NAC策略、SIEM规则库完整覆盖IPv6地址格式及ICMPv6类型代码。  
6. 开展IPv6专项渗透测试：重点验证NDP防护有效性、隧道协议可达性、双栈策略一致性及日志审计覆盖度。
