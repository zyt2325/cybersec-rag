后量子密码

一、基本概念  
1. 后量子密码（PQC）指能抵抗经典计算机和量子计算机攻击的公钥密码算法，不依赖整数分解或离散对数难题。  
2. 其设计目标是在Shor算法可高效破解RSA、ECC等传统公钥体系的背景下，提供长期安全的密钥交换与数字签名方案。  
3. NIST于2017年启动PQC标准化项目，2022年公布首批4种入选算法，涵盖密钥封装机制（KEM）与数字签名两类用途。  
4. PQC并非“抗量子的对称密码”，AES-256等对称算法仅需密钥长度加倍即可抵御Grover算法，不属于PQC范畴。  
5. 当前PQC处于标准化落地初期，尚未完全替代现有PKI体系，需兼顾向后兼容性与迁移路径设计。

二、原理与关键机制  
1. 基于格的密码（如CRYSTALS-Kyber）利用最短向量问题（SVP）和带错误学习问题（LWE）的平均情况困难性构造KEM。  
2. 基于编码的密码（如Classic McEliece）以随机线性码的译码困难性为基础，私钥为特殊结构的生成矩阵，公钥为扰动后的系统码。  
3. 基于哈希的签名（如XMSS、LMS）依赖哈希函数抗碰撞性，通过Merkle树结构实现一次/有限次签名，无数学难题假设。  
4. 多变量公钥密码（如GeMSS）基于求解随机多变量二次方程组的NP难性，但密钥体积大且部分方案已被代数攻击削弱。  
5. 超奇异椭圆曲线同源密码（如SIKE）曾入选NIST第三轮，后因2022年针对性密钥恢复攻击被弃用，凸显PQC分析的持续性。

三、典型类型与常见问题  
1. Kyber是NIST选定的首选KEM标准，具备较小密钥尺寸（~1.5KB）与较快运算速度，但需防范侧信道泄露多项式系数。  
2. Dilithium为首选数字签名标准，基于模块化LWE与模块化SIS问题，签名大小约2.5–4.5KB，验证速度优于ECDSA。  
3. Classic McEliece公钥极大（~1MB），部署受限，但安全性分析历史最长，目前未发现有效密钥恢复攻击。  
4. PQC算法普遍密钥/签名体积显著大于RSA/ECC，导致TLS握手膨胀、证书链存储压力增加及带宽敏感场景适配困难。  
5. 算法实现易受计时侧信道、缓存边信道攻击，尤其格基运算中多项式乘法与采样操作需恒定时间编码。

四、防御措施与实践建议  
1. 采用混合密钥交换（Hybrid KEM）：在TLS 1.3中并行执行X25519与Kyber，任一算法被攻破仍保障前向保密。  
2. 优先升级支持PQC的密码库，如OpenSSL 3.2+、BoringSSL、liboqs，避免自行实现未经验证的PQC原语。  
3. 对证书体系实施分层策略：根CA暂维持RSA-4096，中间CA引入PQC签名，终端实体证书逐步试点Dilithium签名。  
4. 在硬件安全模块（HSM）选型中确认PQC算法支持清单，重点验证Kyber/Dilithium的FIPS 140-3合规实现与侧信道防护等级。  
5. 制定五年迁移路线图，包含协议兼容性测试（如QUIC、S/MIME）、密钥生命周期管理（PQC密钥轮换周期设定为1–3年）及应急回滚机制。
