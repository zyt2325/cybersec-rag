人工智能安全概述  
一、基本概念  
1. 人工智能安全指保障AI系统在开发、部署与运行全生命周期中免受恶意干扰、滥用或失效的能力。  
2. 核心目标包括机密性（防止模型参数与训练数据泄露）、完整性（确保推理结果不被篡改）和可用性（维持服务稳定响应）。  
3. 区别于传统网络安全，AI安全需同时应对数据层、算法层与模型层的新型威胁，如对抗样本、后门触发等。  
4. 安全边界涵盖训练数据、模型架构、权重参数、推理接口及下游应用逻辑，任一环节缺陷均可能导致系统性风险。  

二、原理与关键机制  
1. 对抗样本利用输入数据微小扰动（人眼不可辨）误导模型输出，源于深度神经网络在高维非线性空间中的过拟合特性。  
2. 模型窃取通过查询黑盒API反复获取预测结果，结合迁移学习重建功能近似的替代模型，依赖输出置信度或类别标签信息。  
3. 后门攻击在训练阶段向数据注入特定触发模式（如像素块、频域特征），使模型对含触发样本产生预设错误分类。  
4. 数据投毒通过污染训练集（如翻转标签、注入异常样本），诱导模型学习偏差决策逻辑，影响泛化能力与公平性。  

三、典型类型与常见问题  
1. 推理阶段攻击：对抗样本、模型逆向、成员推断（判断某样本是否参与训练），易导致自动驾驶误判或人脸识别绕过。  
2. 训练阶段攻击：数据投毒、梯度泄漏、分布式训练中的拜占庭节点欺骗，造成模型偏见或全局性能下降。  
3. 模型即服务（MaaS）风险：API暴露置信度分数、软标签或梯度信息，加剧模型窃取与属性推断（如推断用户敏感属性）。  
4. 隐私泄露问题：差分隐私不足时，生成式AI可能复现训练数据中的个人身份信息（PII）或受版权保护内容。  
5. 供应链风险：依赖第三方预训练模型、开源框架或数据集，引入未审计的后门、漏洞或偏见组件。  

四、防御措施与实践建议  
1. 输入净化：部署对抗训练（PGD对抗样本增强）、随机化预处理（如JPEG压缩、位深度缩减）提升鲁棒性。  
2. 模型加固：采用差分隐私训练（添加可控噪声）、联邦学习（原始数据不出本地）、可信执行环境（TEE）保护推理过程。  
3. 访问控制：限制API输出粒度（禁用置信度、仅返回硬标签），实施速率限制与查询指纹识别，阻断批量窃取尝试。  
4. 供应链治理：对第三方模型执行完整性校验（哈希比对）、后门检测（如神经元激活分析）、许可证合规审查。  
5. 全流程审计：记录训练数据来源与标注质量，监控推理延迟与输出分布偏移，建立模型行为基线用于异常告警。  
6. 红蓝对抗演练：定期开展AI专项渗透测试，覆盖数据投毒模拟、对抗样本生成、成员推断验证等场景，验证防御有效性。
