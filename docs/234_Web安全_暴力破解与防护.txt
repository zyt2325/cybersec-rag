暴力破解与防护

一、基本概念  
1. 暴力破解是一种通过系统性尝试所有可能的密码组合来获取合法凭证的攻击方法。  
2. 其核心依赖于密码空间的有限性与用户设置弱口令的普遍性，而非算法漏洞。  
3. 攻击目标包括登录接口、加密密钥、API密钥、Wi-Fi预共享密钥（PSK）等认证凭据。  
4. 与字典攻击不同，纯暴力破解不依赖预置词表，而是按固定顺序穷举全部字符组合。  
5. 实际攻击中常与字典攻击混合使用，先尝试高频口令再扩展至全量组合。

二、原理与关键机制  
1. 攻击者利用认证系统未设访问频率限制或响应延迟机制，实现高速请求提交。  
2. 通过自动化工具模拟大量登录请求，依据服务端返回状态码（如HTTP 200/401）判断凭证有效性。  
3. 密码熵值决定破解难度：8位纯小写字母组合约2.1×10¹⁰种可能，而含大小写数字符号的12位密码超9×10²⁰种。  
4. 离线暴力破解更高效，攻击者获取哈希值后可在本地GPU集群上并行计算，规避网络限速。  
5. 认证协议设计缺陷（如无盐哈希、明文传输）显著降低暴力破解门槛。

三、典型类型与常见问题  
1. 在线暴力破解：针对Web登录、SSH、RDP等服务，易受速率限制影响但无需前置数据泄露。  
2. 离线暴力破解：攻击者已窃取数据库中的密码哈希，可无限次尝试且不触发账户锁定。  
3. 针对多因素认证（MFA）的暴力破解聚焦于备用验证通道，如短信验证码重放或TOTP时间窗口试探。  
4. 常见问题包括：管理员账户未启用强密码策略、旧系统使用DES或MD5等弱哈希算法、会话令牌未绑定IP或设备指纹。  
5. 云环境因API密钥长期有效且权限过大，成为暴力破解高价值目标。

四、防御措施与实践建议  
1. 强制实施最小8位、含四类字符的密码策略，并禁用常见弱口令（如password123、admin123）。  
2. 采用带随机盐值的现代哈希算法（如bcrypt、scrypt、Argon2）存储密码，增加离线破解成本。  
3. 部署基于时间窗口的登录失败计数机制，连续5次失败后锁定账户30分钟或要求人工审核。  
4. 对登录接口实施速率限制（如每IP每分钟最多6次请求）并引入CAPTCHA人机识别。  
5. 启用多因素认证（MFA），优先选择基于FIDO2/WebAuthn的硬件密钥或推送验证，避免仅依赖SMS。  
6. 定期审计日志，监控异常登录行为（如非工作时间高频失败、跨地域IP短时并发请求），并联动SIEM告警。
