ARP欺骗与防御

一、基本概念  
1. ARP欺骗是一种局域网内基于地址解析协议（ARP）设计缺陷的中间人攻击技术。  
2. 攻击者通过伪造ARP响应报文，篡改目标主机或网关的ARP缓存表项。  
3. 该攻击仅在二层广播域内生效，无法跨路由器传播，依赖以太网环境。  
4. 欺骗成功后，受害主机将数据帧错误发送至攻击者MAC地址，造成流量劫持或中断。  
5. ARP协议本身无身份认证机制，且缓存更新采用“后到优先”策略，构成根本脆弱性。

二、原理与关键机制  
1. 正常ARP通信中，主机通过广播ARP请求获取IP对应的MAC地址，接收单播ARP应答并缓存。  
2. 攻击者主动发送伪造的ARP应答（ Gratuitous ARP 或 Unrequested Reply），无需等待请求。  
3. 目标主机收到后不验证源IP与发送者一致性，直接覆盖原有ARP缓存条目。  
4. 网关设备同样遵循相同缓存更新逻辑，导致双向流量均经攻击者中转。  
5. 欺骗可单向（仅污染主机→网关映射）或双向（同时污染主机↔网关双向映射）。  
6. 攻击持续依赖周期性发送伪造报文，以维持缓存有效，避免被超时清除。

三、典型类型与常见问题  
1. 中间人窃听：攻击者截获并转发通信流量，实现明文密码、会话Cookie等敏感信息获取。  
2. 流量丢弃：伪造应答后不转发数据，导致目标主机与网关间连接中断，形成拒绝服务。  
3. DNS劫持配合：结合DNS欺骗，将用户请求重定向至恶意网站，提升钓鱼成功率。  
4. 多点并发欺骗：同一攻击者同时对多个主机实施ARP欺骗，扩大影响范围。  
5. 混合攻击载体：常作为勒索软件、木马传播的前置环节，用于内网横向渗透。  
6. 日志缺失：多数交换机不记录ARP操作，传统防火墙难以检测未加密的ARP异常流量。

四、防御措施与实践建议  
1. 启用静态ARP绑定：对关键服务器和网关配置静态ARP表项，禁用动态更新功能。  
2. 部署ARP检测机制：交换机启用DAI（Dynamic ARP Inspection），校验ARP报文与DHCP Snooping绑定表一致性。  
3. 划分VLAN隔离：缩小广播域范围，限制ARP欺骗影响半径，降低横向扩散风险。  
4. 使用ARP防火墙软件：在终端部署具备ARP行为监控与自动恢复能力的安全代理。  
5. 启用端口安全策略：交换机配置MAC地址绑定与学习数量限制，阻断非法设备接入。  
6. 结合802.1X认证：在接入层强制执行用户身份鉴权，从准入环节抑制未授权设备发起欺骗。
