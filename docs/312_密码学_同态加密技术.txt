同态加密技术

一、基本概念  
1. 同态加密是一种允许对密文直接执行特定代数运算，解密后结果等同于对明文进行相同运算的公钥加密范式。  
2. 其核心目标是在不暴露原始数据的前提下，支持第三方在加密数据上完成可信计算任务。  
3. 区别于传统加密，同态加密强调“运算保持性”，即加法同态、乘法同态或两者兼备的数学结构。  
4. 适用于隐私保护场景，如医疗数据分析、金融风控外包计算、联邦学习中的梯度聚合等。  

二、原理与关键机制  
1. 基于困难数学问题构建：典型方案依赖RLWE（环上带错误学习）、LWE（带错误学习）或理想格上的离散高斯采样难题。  
2. 密文包含噪声项，每次同态运算会放大噪声；当噪声超过阈值时解密失败，此为正确性边界约束。  
3. 采用密钥交换与重线性化技术控制噪声增长，如BGV、BFV方案使用模数切换（modulus switching）降噪。  
4. 支持自举（bootstrapping）操作的全同态加密（FHE）可刷新密文噪声，理论上支持任意深度电路计算。  

三、典型类型与常见问题  
1. 部分同态加密（PHE）仅支持有限次加法或乘法，如Paillier支持加法同态，RSA支持乘法同态。  
2. 层级同态加密（SHE）支持有界深度的加法与乘法组合，如CKKS方案适用于近似复数/实数计算。  
3. 全同态加密（FHE）理论上支持任意计算，但自举开销大，当前实现中单次自举耗时数百毫秒至数秒。  
4. 效率瓶颈显著：密文膨胀率常达1000–10000倍，计算吞吐量比明文低3–6个数量级。  
5. 参数选择不当易导致安全性降级：过小的模数或噪声分布偏差可能削弱抗攻击能力。  

四、防御措施与实践建议  
1. 根据应用场景严格选型：敏感整数统计用Paillier，机器学习推理用CKKS，通用逻辑计算审慎评估FHE可行性。  
2. 实施密文生命周期管理：设定密文有效时长，禁止长期缓存高噪声密文，定期触发密钥轮换与密文重加密。  
3. 在可信执行环境（TEE）中协同部署：将同态计算与SGX/SEV结合，弥补FHE性能短板并增强侧信道防护。  
4. 对输入数据预处理：实施范围裁剪与定点数缩放，避免CKKS等方案因溢出导致精度崩溃或解密失败。  
5. 验证第三方计算完整性：集成可验证计算协议（如zk-SNARKs），确保外包同态运算未被篡改或跳过。  
6. 遵循NIST PQC标准演进：关注FHE参数标准化进展（如NIST FHE标准草案），避免使用非认证自研变种方案。
