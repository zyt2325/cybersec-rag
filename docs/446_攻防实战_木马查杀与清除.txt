木马查杀与清除

一、基本概念  
1. 木马（Trojan）是一种伪装成合法软件的恶意程序，不具备自我复制能力，依赖用户主动执行。  
2. 木马核心目标是建立隐蔽通信通道，为攻击者提供远程控制、数据窃取或系统持久化访问权限。  
3. 与病毒不同，木马不感染其他文件，但常通过捆绑下载、钓鱼邮件、盗版软件等途径传播。  
4. 木马一旦运行，通常在内存中驻留，并可能修改注册表启动项、服务、计划任务等实现开机自启。  
5. 查杀指识别并终止木马进程、删除其文件及关联配置；清除强调彻底移除残留痕迹与后门组件。

二、原理与关键机制  
1. 木马常采用进程注入、DLL劫持、APC注入等技术将恶意代码注入合法进程中以规避检测。  
2. 通信阶段多使用HTTP/S、DNS隧道或加密TCP连接，部分木马支持域生成算法（DGA）动态生成C2域名。  
3. 持久化机制包括创建Windows服务、写入Run键、利用WMI事件订阅、或滥用COM对象劫持等。  
4. 反调试与反虚拟机技术常见，如检查父进程名、检测调试器API调用、判断CPU指令执行时间异常。  
5. 加壳与混淆广泛用于逃避静态特征扫描，UPX、VMProtect、ConfuserEx等工具被频繁滥用。

三、典型类型与常见问题  
1. 远控木马（RAT）如DarkComet、NanoCore，提供屏幕监控、键盘记录、文件上传下载等功能。  
2. 下载器木马专用于二次下载其他恶意负载，常无独立恶意行为，但极难被传统规则识别。  
3. 无文件木马利用PowerShell、WMI、宏脚本或内存反射加载技术，不落盘即可执行。  
4. 隐蔽性问题突出：部分木马启用Rootkit级驱动，隐藏进程、文件、网络连接，导致常规任务管理器无法发现。  
5. 清除不彻底易引发反复感染，常见原因包括未清理注册表劫持项、残留计划任务或服务残留。

四、防御措施与实践建议  
1. 启用基于行为的EDR方案，实时监控进程创建链、异常网络连接、敏感API调用（如VirtualAlloc+WriteProcessMemory）。  
2. 定期核查启动项（msconfig、Autoruns）、服务列表（sc query）、计划任务（schtasks /query），比对签名与路径可信度。  
3. 使用内存取证工具（如Volatility）分析可疑进程的内存镜像，识别注入代码与未导出函数调用。  
4. 对疑似样本进行多引擎在线扫描（VirusTotal），结合静态特征（导入表、字符串、节区熵值）与动态行为日志交叉验证。  
5. 清除后需重置高危凭证（本地管理员、域账户密码），禁用不必要的远程管理协议（如RDP、SMBv1），并更新系统补丁。  
6. 建立最小权限原则：普通用户禁用管理员权限，限制PowerShell执行策略为AllSigned或Restricted。
