模型窃取攻击

一、基本概念  
1. 模型窃取攻击是指攻击者通过合法查询目标机器学习模型的API接口，逆向重建其功能等价或高度近似的替代模型。  
2. 该攻击不依赖对训练数据或模型参数的直接访问，属于黑盒场景下的模型知识产权侵害行为。  
3. 窃取目标包括商业AI服务（如人脸识别、信用评分API）、联邦学习中的聚合模型及边缘部署的轻量化模型。  
4. 攻击成功标志是替代模型在测试集上达到与原模型相近的准确率，且结构可被用于再训练、迁移或规避检测。  

二、原理与关键机制  
1. 核心依赖模型输出的可预测性：分类模型的置信度分数、回归模型的连续输出均含梯度信息，可被采样建模。  
2. 查询-响应对构成伪标签数据集：攻击者构造输入样本并收集模型输出（如logits、概率分布），形成监督学习所需的训练数据。  
3. 边界探索技术用于提升数据质量：通过对抗扰动或输入空间遍历，定位决策边界附近样本，增强替代模型判别能力。  
4. 温度缩放（Temperature Scaling）常被用于软化输出分布，使softmax logits更易拟合，提高知识蒸馏效率。  

三、典型类型与常见问题  
1. 查询式模型提取：通过高频调用API获取足够多（通常数万级）输入-输出对，训练替代模型，成本取决于API限流策略。  
2. 成员推理辅助窃取：先利用成员推理判断某样本是否属训练集，再针对性采样，提升替代模型在敏感子域上的保真度。  
3. 多阶段窃取：首阶段恢复模型架构（如层数、激活函数），次阶段优化权重，适用于输出受限（仅预测类别）的严苛黑盒环境。  
4. 常见失效原因包括：目标模型启用输出截断（仅返回top-1类别）、添加随机噪声、实施查询频率限制或输入合法性校验。  

四、防御措施与实践建议  
1. 输出扰动防御：对logits添加可控高斯噪声或应用差分隐私机制，在可用性与模型保密度间取得平衡。  
2. 查询速率限制与异常检测：基于IP、token或用户行为建模识别高频/模式化查询，动态调整响应策略。  
3. 架构混淆：部署时隐藏真实网络结构，例如使用模型封装层统一处理输入/输出，避免暴露中间层特征。  
4. 水印嵌入：在模型决策边界中植入不可见但可验证的统计指纹，用于事后溯源窃取模型而非事前阻止。  
5. 合同与日志管控：在API服务协议中明确禁止批量查询行为，并完整记录请求元数据（时间戳、输入哈希、响应摘要）以支持审计。  
6. 分层防御设计：将输出裁剪、查询节流、水印与法律条款结合，单一措施易被绕过，需构建纵深防护体系。
