内网渗透基础

一、基本概念  
1. 内网渗透指攻击者在已获取边界设备（如Web服务器、防火墙）初始访问权限后，向内部网络横向移动并提升权限的过程。  
2. 内网通常指组织内部受控网络区域，与互联网隔离或仅通过严格策略通信，常见于企业办公网、生产网等场景。  
3. 初始立足点（FOOTING）是渗透起点，常为DMZ区主机、远程办公终端或被钓鱼的员工工作站。  
4. 横向移动（Lateral Movement）是核心行为，指利用内网协议、凭证、信任关系在主机间转移控制权。  
5. 权限提升（Privilege Escalation）既包括本地提权（如利用内核漏洞获取SYSTEM），也包括域内提权（如获取域管理员令牌）。  

二、原理与关键机制  
1. 依赖内网固有信任模型：如Windows域环境默认启用SMB签名禁用、NTLM中继、Kerberos委派等弱安全配置。  
2. 利用协议设计特性：LLMNR/NBT-NS响应劫持可触发凭证中继；SMB会话复用允许凭据重放；LDAP匿名查询可能泄露账户信息。  
3. 凭证复用是关键突破口：员工在多系统使用相同密码，导致一台主机失陷后可批量爆破其他服务。  
4. 网络分段失效放大风险：VLAN未隔离关键子网、防火墙策略宽泛（如any-to-any规则）、无微隔离措施均助长横向扩散。  
5. 日志缺失或集中度低阻碍检测：终端无进程命令行日志、域控制器未启用Kerberos审计、SIEM未关联多源事件。  

三、典型类型与常见问题  
1. 基于凭证的攻击：如Mimikatz提取LSASS内存明文密码、DPAPI密钥解密浏览器保存口令、Pass-the-Hash重用NTLM哈希。  
2. 协议中继攻击：将LLMNR/NBT-NS响应捕获的Net-NTLMv2哈希中继至SMB或LDAP服务完成认证。  
3. 域环境特有路径：利用Golden Ticket伪造域管理员票据、DCSync同步域控数据库、Abuse of ACLs修改对象控制权限。  
4. 服务漏洞利用：如Exchange Server ProxyLogon、Print Spooler PrintNightmare、Zabbix Java反序列化等内网服务高危漏洞。  
5. 云混合环境风险：Azure AD Connect同步配置错误、混合域信任关系暴露、本地AD与云身份联合策略缺陷引发越界访问。  

四、防御措施与实践建议  
1. 实施最小权限原则：禁用本地管理员组域账户、限制域用户加入本地管理员组、启用UAC远程限制策略。  
2. 强制协议安全加固：全域启用SMB签名与加密、禁用NTLMv1、配置LDAP通道绑定与SSL/TLS强制、关闭LLMNR/NBT-NS。  
3. 完善凭证生命周期管理：部署密码哈希同步保护（PHS）、启用FIDO2多因素认证、定期轮换KRBTGT账户密码两次以上。  
4. 构建纵深检测能力：在域控制器启用4662/4769/4776等关键事件审计，在终端部署EDR采集进程树与网络连接上下文。  
5. 推行网络微隔离：按业务功能划分VLAN并配置ACL限制跨子网通信，对数据库、域控等关键资产实施主机级防火墙白名单。  
6. 开展常态化红蓝对抗：每季度执行基于ATT&CK框架的内网渗透演练，重点验证横向移动链路阻断有效性及响应时效性。
