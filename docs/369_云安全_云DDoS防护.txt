云DDoS防护  

一、基本概念  
1. 云DDoS防护是依托云服务商基础设施提供的分布式拒绝服务攻击实时检测与流量清洗服务。  
2. 区别于本地硬件设备，其防护能力弹性扩展，可应对Tbps级攻击流量，无需用户自建清洗中心。  
3. 服务通常按带宽峰值、请求数或防护时长计费，支持按需启用和自动扩缩容。  
4. 防护对象涵盖Web应用、API网关、游戏服务器、DNS服务等云上暴露面资产。  
5. 云厂商一般提供多层防护：网络层（L3/L4）与应用层（L7）协同防御，覆盖SYN Flood、HTTP Flood等场景。  

二、原理与关键机制  
1. 流量牵引机制：通过BGP路由宣告或DNS重定向，将异常流量实时导入云清洗中心。  
2. 行为基线建模：基于历史流量特征（如QPS、连接数、UA分布）建立动态基线，识别偏离行为。  
3. 挑战响应验证：对疑似恶意IP实施CAPTCHA、JavaScript计算挑战或TCP三次握手增强验证。  
4. 分布式清洗集群：利用全球边缘节点就近清洗，降低回源延迟，避免骨干网拥塞。  
5. 自动化策略引擎：支持基于规则（如源IP频次阈值）与AI模型（如LSTM时序异常检测）双驱动决策。  

三、典型类型与常见问题  
1. 反射放大攻击（如NTP/SSDP反射）：攻击者伪造源IP向开放服务发送小请求，触发大响应洪泛目标。  
2. 应用层慢速攻击（如Slowloris、R-U-Dead-Yet）：维持大量半开连接耗尽Web服务器连接池资源。  
3. DNS查询泛洪：高频随机子域名请求冲击权威DNS服务器，导致解析服务不可用。  
4. 云环境特有风险：API密钥泄露引发自动化Bot刷量；Serverless函数冷启动加剧响应延迟敏感性。  
5. 防护盲区：未接入云防护的裸金属服务器、跨云多活架构中非主控云平台流量未被统一调度。  

四、防御措施与实践建议  
1. 启用云服务商默认DDoS基础防护（如阿里云DDoS基础版、AWS Shield Standard），覆盖常规L3/L4攻击。  
2. 对高价值业务启用增强防护（如AWS Shield Advanced、腾讯云大禹），获取7×24专家响应与攻击溯源支持。  
3. 配置Web应用防火墙（WAF）联动策略，在L7层实施URL频率限制、Bot行为指纹识别与JS挑战。  
4. 实施最小化暴露原则：关闭非必要端口，使用私有网络VPC部署核心组件，限制公网访问范围。  
5. 定期开展红蓝对抗演练，模拟不同攻击向量（如UDP碎片攻击、HTTPS慢速POST），验证清洗策略有效性。  
6. 部署多云流量监控看板，聚合各云平台NetFlow/IPFIX日志，实现跨域攻击趋势分析与协同响应。
