差分隐私

一、基本概念  
1. 差分隐私是一种严格的数学隐私定义，确保单个个体数据加入或退出数据集时，查询结果分布差异被严格控制。  
2. 核心目标是防止攻击者通过分析发布统计结果推断特定个体是否存在或其敏感属性值。  
3. 由ε（隐私预算）量化隐私保护强度，ε越小表示隐私保障越强，但可用性通常下降。  
4. 不依赖攻击者背景知识假设，提供对任意先验知识和辅助信息的鲁棒性防御。  
5. 区别于k-匿名、l-多样性等传统脱敏技术，差分隐私具备可证明的、可组合的隐私保证。

二、原理与关键机制  
1. 通过向查询结果注入受控随机噪声实现隐私保护，常用拉普拉斯机制和高斯机制。  
2. 噪声幅度由查询的全局敏感度决定，即单个记录变动导致查询结果的最大变化量。  
3. 满足(ε,δ)-差分隐私需满足Pr[M(D)∈S] ≤ e^ε·Pr[M(D′)∈S] + δ，其中D与D′仅相差一条记录。  
4. 隐私预算ε可跨多次查询分配与消耗，满足序列组合定理与并行组合定理。  
5. 采样机制（如Privacy Amplification by Sampling）可降低实际ε消耗，提升效用。

三、典型类型与常见问题  
1. 本地差分隐私（LDP）要求个体在提交前加噪，适用于不可信服务器场景，但噪声开销显著更高。  
2. 中心化差分隐私假设可信聚合方，噪声添加在服务端完成，效用优于LDP但依赖信任假设。  
3. 交互式模型中，攻击者可能通过精心设计的自适应查询耗尽隐私预算，引发预算泄露风险。  
4. 非数值型查询（如直方图、机器学习模型参数）需适配敏感度计算与噪声机制，易引入偏差。  
5. 多维数据联合发布时，若未协调各维度预算分配，可能导致整体隐私保障失效。

四、防御措施与实践建议  
1. 采用隐私预算会计工具（如Google’s DP Library、IBM Diffprivlib）跟踪ε累积，避免超支。  
2. 对高敏感度查询（如COUNT(*) WHERE condition）优先使用平滑敏感度或裁剪技术降低噪声需求。  
3. 在机器学习中集成差分隐私训练（如DP-SGD），通过梯度裁剪与高斯噪声保障模型参数隐私。  
4. 发布前验证机制是否满足(ε,δ)-差分隐私定义，使用统计检验或形式化验证工具辅助确认。  
5. 结合合成数据生成（如PATE框架）将隐私保护嵌入模型输出阶段，缓解原始数据暴露风险。  
6. 明确披露所用ε值、δ值、噪声机制及数据处理流程，确保透明性与合规性（如GDPR第25条）。
