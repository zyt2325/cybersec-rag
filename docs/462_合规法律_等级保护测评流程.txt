等级保护测评流程

一、基本概念  
1. 等级保护测评是依据《网络安全法》《等保2.0基本要求》等法规，对网络系统安全保护能力进行的符合性与有效性验证活动。  
2. 测评对象包括定级系统及其承载的物理环境、网络架构、主机设备、应用系统和数据资源等全要素。  
3. 测评工作由具备资质的第三方测评机构实施，覆盖技术测评（安全物理环境至安全管理中心）和管理测评（安全管理制度至安全应急处置）两大维度。  
4. 测评结论分为“符合”“基本符合”“不符合”三类，其中“基本符合”需在30个工作日内完成整改并复测。  

二、原理与关键机制  
1. 测评遵循“以保护对象为核心、以控制措施为路径、以风险结果为导向”的闭环验证逻辑。  
2. 采用“核查+测试+访谈+文档审查”四维方法组合：核查配置策略、测试防护功能、访谈责任人、审查制度记录。  
3. 关键机制包括测评指标映射（将GB/T 22239—2019条款逐条对应到被测系统具体组件）、证据链构建（每项指标需提供可追溯的配置截图、日志片段、制度文件编号等三类以上证据）。  
4. 测评过程实行“双人复核制”，技术测试结果须经主测工程师与复核工程师独立验证签字确认。  

三、典型类型与常见问题  
1. 常见类型包括新建系统上线前测评、在运系统年度复测、重大变更后专项测评及跨省联网系统协同测评。  
2. 典型问题包括：等保定级不准导致测评范围缺失；安全设备策略未启用或规则库过期；日志留存不足180天且未集中审计。  
3. 管理层面高频缺陷：应急预案未开展实战演练、安全培训记录缺失连续两年、外包人员权限未按最小化原则管控。  
4. 技术层面突出短板：边界防火墙未开启深度包检测（DPI）功能；数据库未启用强制访问控制（MAC）或字段级加密。  

四、防御措施与实践建议  
1. 系统建设初期即嵌入等保设计：网络区域划分应满足安全通信网络要求，部署冗余链路与双机热备架构。  
2. 建立常态化自评估机制：每季度对照等保2.0三级要求开展配置核查，使用自动化工具扫描弱口令、未授权访问、高危端口开放等问题。  
3. 安全设备策略须与业务场景强绑定：如Web应用防火墙（WAF）规则应覆盖OWASP Top 10攻击特征，且每季度更新规则库并验证拦截效果。  
4. 日志管理必须实现“采集—传输—存储—分析”全链路可控：日志服务器独立部署、时间同步精度≤100ms、原始日志不可删改且保留≥180天。  
5. 人员能力需匹配测评要求：安全管理员须持CISP-PTE或CISAW证书，关键岗位实行AB角机制，权限交接留痕并双人审批。
