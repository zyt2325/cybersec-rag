数据安全法要点  
一、基本概念  
1. 《中华人民共和国数据安全法》于2021年9月1日起施行，是我国首部专门规范数据处理活动的基础性法律。  
2. 法律所称“数据”指任何以电子或其他方式对信息的记录，包括公共数据、企业数据、个人信息等各类数据形态。  
3. “数据安全”指通过采取必要措施，确保数据处于有效保护和合法利用状态，防范数据泄露、篡改、损毁及非法获取。  
4. 数据处理活动涵盖数据的收集、存储、使用、加工、传输、提供、公开、删除等全生命周期环节。  
5. 国家建立数据分类分级保护制度，依据数据在经济社会发展中的重要程度及危害程度，划分核心数据、重要数据与一般数据。  

二、原理与关键机制  
1. 实行数据安全责任制，明确数据处理者是数据安全第一责任人，须建立健全全流程数据安全管理制度。  
2. 关键信息基础设施运营者和处理重要数据的组织，须设立数据安全管理机构并指定数据安全负责人。  
3. 开展数据处理活动前应进行风险评估，重点评估数据类型、规模、处理方式、安全防护能力及潜在危害。  
4. 境外司法或执法机构调取境内数据，须经国家网信部门批准，不得擅自提供；确需配合的须履行法定程序。  
5. 国家建立数据安全审查制度，对影响或可能影响国家安全的数据处理活动实施事前审查。  

三、典型类型与常见问题  
1. 重要数据识别不清：部分企业未按行业目录或地方标准识别本单位重要数据，导致保护措施缺位。  
2. 跨境数据传输违规：未经安全评估、认证或标准合同备案，向境外提供重要数据或大量个人信息。  
3. 数据共享缺乏管控：内部系统间、政企间数据共享未签订安全协议，未落实最小必要原则与访问权限控制。  
4. 第三方管理薄弱：委托处理数据时未审核受托方资质，未约定数据安全责任，未监督其处理行为。  
5. 日志留存不足：未按要求保存数据处理操作日志不少于6个月，影响安全事件溯源与合规审计。  

四、防御措施与实践建议  
1. 建立数据资产清单，动态标注数据类别、级别、处理环节、存储位置及责任人，支撑分类分级落地。  
2. 部署数据防泄漏（DLP）系统，对敏感数据识别、加密、水印、访问控制与异常传输行为实施实时监测阻断。  
3. 对重要数据实施加密存储与传输，密钥由独立密钥管理系统（KMS）统一管理，禁止硬编码或明文存储。  
4. 开展常态化数据安全培训，覆盖开发、运维、业务人员，重点强化最小必要、知情同意、目的限制等合规意识。  
5. 每年至少组织一次数据安全应急演练，检验应急预案有效性，确保72小时内向主管部门报告数据安全事件。  
6. 委托处理数据前须完成尽职调查，签订含数据安全条款的书面协议，明确处理目的、期限、技术措施及违约责任。
