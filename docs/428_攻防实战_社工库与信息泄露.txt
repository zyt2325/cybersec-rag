社工库与信息泄露

一、基本概念  
1. 社工库是攻击者非法收集、整理并结构化存储的个人敏感信息数据库，常用于社会工程学攻击。  
2. 信息泄露指组织或个人因安全疏失、系统漏洞或内部人员违规导致数据非授权暴露于公共或黑产渠道。  
3. 社工库数据多源自历史漏洞（如Struts2、ThinkPHP远程代码执行）、弱口令爆破及钓鱼平台批量注册。  
4. 典型字段包括邮箱、手机号、明文/弱加密密码、身份证号、用户名及关联社交账号，部分含消费记录与设备指纹。  
5. 数据流通常经暗网论坛、Telegram频道及加密货币交易完成，单条有效邮箱+密码组合黑市售价0.1–5美元不等。

二、原理与关键机制  
1. 攻击者利用网站未脱敏日志、数据库备份误传至公网、API接口未鉴权等缺陷批量导出原始数据。  
2. 密码复用现象使单一平台泄露可横向突破多个账户，尤其影响金融、政务类高权限系统。  
3. 哈希碰撞与彩虹表攻击可逆向破解MD5、SHA1等弱哈希密码，尤其当缺乏盐值（salt）时成功率超70%。  
4. 爬虫结合OCR识别扫描公开简历、企业黄页、法院文书等半结构化数据，补充社工库字段完整性。  
5. 部分社工库采用分层索引机制：按地域、行业、职级建立标签体系，支持条件组合检索提升攻击精准度。

三、典型类型与常见问题  
1. 历史漏洞库：如2011年CSDN明文密码库、2016年京东用户数据泄露，至今仍被用于撞库攻击。  
2. 黑产定制库：通过恶意APP静默采集通讯录、短信、剪贴板内容，定向生成高价值目标子库。  
3. 供应链泄露：第三方SDK、云服务商配置错误导致客户数据连带暴露，占近年重大泄露事件的42%（Verizon DBIR 2023）。  
4. 员工凭证滥用：内部人员出售OA系统账号密码，使攻击者绕过边界防护直接访问核心业务数据库。  
5. 搜索引擎缓存泄露：Google Hacking语法（如site:xxx.com filetype:sql）可定位未删除的数据库文件快照。

四、防御措施与实践建议  
1. 强制实施密码策略：禁用常见弱口令，要求8位以上含大小写字母、数字、符号，启用自适应哈希（如Argon2）。  
2. 敏感数据分级管控：身份证号、银行卡号等PII字段须加密存储（AES-256-GCM），前端传输禁用明文提交。  
3. 定期开展渗透测试与源码审计，重点检查日志输出、错误页面、备份文件路径及API接口鉴权逻辑。  
4. 部署数据库活动监控（DAM）系统，对非常规时段、高频次SELECT语句及大范围导出行为实时告警。  
5. 员工安全意识培训需覆盖钓鱼邮件识别、USB设备禁用策略、双因素认证强制启用等实操要点。  
6. 建立泄露响应机制：接入Shodan、HaveIBeenPwned等监测服务，发现匹配数据后2小时内启动密码重置与日志溯源。
